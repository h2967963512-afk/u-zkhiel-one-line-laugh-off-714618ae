An original one-liner for the One-Line Laugh-Off: my AI assistant files for overtime, because listening to me think out loud counts as emotional labor. The joke flips the usual human–machine dynamic — the tireless helper is the overworked employee, and the user is the difficult boss. `main.ts` writes the line to `/output/entry.txt` with a fail-fast check that it stays within the 1–200 character gate.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
